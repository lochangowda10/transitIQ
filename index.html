      How it works

      Dijkstra
      01

      Build the graph

      Each station is a node. Consecutive stations on a line are joined by an edge weighted at km × 2.5 minutes, rounded to the nearest minute.

      02

      Search for the fastest path

      Dijkstra's algorithm explores the network from the origin and settles each station at its lowest known time. The first time the destination is settled, the fastest path is known.

      03

      Pay for the change

      The search tracks which line you arrive on. Switching between Purple and Green at Majestic costs an extra 4 minutes, so a one-change route is only chosen when it genuinely wins.

      04

      Add waiting, then price the trip

      Each boarding leg adds 2 minutes of platform wait off-peak or 5 minutes at peak. Distance is summed along the path and matched to the fare slab.

      Honesty note This is a static teaching model. It does not know live train positions, disruption, walking time inside stations or accessibility requirements. Treat every number as an estimate.
